# Қауымдық сервитут белгілеу туралы

Қазақстан Республикасы Жер кодексінің 19, 69-баптарына, 71-1-бабының 2-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 35-бабына сәйкес Набережный ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. «Соколов-Сарыбай тау-кен байыту өндірістік бірлестігі» акционерлік қоғамына пайдалы қазбаларды барлау жөніндегі операцияларды жүргізу үшін Набережный ауылдық округінің жерінде орналасқан, жалпы алаңы 130,3 гектар, жер учаскелеріне қауымдық сервитут белгіленсін.

<a id="p2"></a>

2. «Набережный ауылдық округі әкімінің аппараты» мемлекеттік мекемесі Қазақстан Республикасының заңнамасында белгіленген тәртіпте:

   1) осы шешімді Қазақстан Республикасы нормативтік құқықтық актілерінің эталондық бақылау банкінде ресми жариялауға жіберуді;

   2) осы шешімді ресми жарияланғанынан кейін Бейімбет Майлин ауданы әкімдігінің интернет-ресурсында орналастырылуын қамтамасыз етсін.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.
