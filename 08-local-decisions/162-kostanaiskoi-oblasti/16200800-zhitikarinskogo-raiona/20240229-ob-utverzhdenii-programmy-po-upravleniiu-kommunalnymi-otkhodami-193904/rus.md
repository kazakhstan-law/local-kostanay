# Об утверждении программы по управлению коммунальными отходами по Житикаринскому району на 2024-2030 годы

В соответствии с подпунктом 1) пункта 3 статьи 365 Экологического кодекса Республики Казахстан Житикаринский районный маслихат РЕШИЛ:

1. Утвердить программу по управлению коммунальными отходами по Житикаринскому району на 2024-2030 годы согласно приложению к настоящему решению.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Председатель Житикаринского районного маслихата**

**Н. Уразалинов**

> *Приложение*  
> *к решению маслихата*  
> *от 29 февраля 2024 года*  
> *№ 128*
