# Жер салығы базалық ставкаларының өзгерістері туралы

> *Ескерту. Күші жойылды - Қостанай облысы Қарасу ауданы мәслихатының 09.04.2007 № 256 шешімімен.*

Жергілікті бюджеттін табыс бөлігін ұлғайту мақсатында және «Салық және бюджетке төленетін басқа да міндетті төлемдері туралы» Қазақстан Республикасы Кодексінің 338-бабының 1-тармағына сәйкес, Қазақстан Республикасының жер зандарына сәйкес өткізілген жерді аймақтарға бөлу жобалары негізінде, Қарасу аудандық мәслихаты ШЕШТІ:

<a id="p1"></a>

1. Елді мекендердін тыс өнеркәсіп жерлері мен ауыл шаруашылығына жататың жерлерге жер салығының базалық ставкаларың 50 пайызға ұлғайту.

<a id="p2"></a>

2. Салық комитеті жер салығың ұлғайтылған базалық ставкалардың негізінде осы шешімге сәйкес есептеу жүргізсін.

<a id="p3"></a>

3. «Жер салығы базалық ставкаларының өзгерістері туралы» Қарасу аудандық мәслихатының 2005 жылғы 3 наурыздағы № 88 шешімінің күші жойылды деп танылсын, ( 3379 мемлекеттік тіркеу нөмірі, «За изобилие» 2005 жылғы 25 наурыздағы № 10).

<a id="p4"></a>

4. Осы шешімінің орындалуын бақылау Қарасу ауданы бойынша салық комитетінің төрағасы Шоқметов Ғалымбек Қабдешұлына жүктелсін.

<a id="p5"></a>

5. Осы шешім ресми жарияланған күнінен бастап он күнтізбелік күн өткеннен кейін қолданысқа енеді.
