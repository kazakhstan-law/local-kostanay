# Кепілдік сапасы бар өнімдерді шығаруды қамтамасыз ету жөніндегі шаралар туралы

> *Ескерту. Күші жойылды - Қостанай облысы әкімінің 09.12.2004 № 53 шешімімен.*

"Тұрғындардың санитарлық-эпидемиологиялық ахуалын жақсарту туралы" Қазақстан Республикасы Заңының 38-ші бабының негізінде кепілдік сапасы бар өнімдерді шығаруды қамтамасыз ету мақсатында ШЕШТIМ:

1. Меншік нысандарына қарамастан азық-түлік тауарларын және халық тұтыну тауарларын шығарумен айналысушы шаруашылық жүргізуші субъектілер (тізбеге сәйкес):

   - лабораториялық бақылау өткізбей өнімдерді шығаруға және өткізуге жол бермесін;

   - өндірістік лабороториялар болмаған немесе оларды ашу мүмкіндігі жоқ жағдайларда зерттеулерді аумақтық санэпидқызмет органдарында келісім-шарт негізінде жүргізсін.

2. Осы шешімнің орындалуына бақылау жасау облыс әкімінің орынбасары С.А. Құланбаевқа жүктелсін.

## Санитарлық ережелер, нормалар және ГОСТ-тарға сәйкес өнімдері өндірістік лабораториялық бақылауға жатқызылған кәсіпорындардың ТІЗБЕСІ

1. Нан зауыттары мен наубайханалар

2. Кондитерлік цехтар

<a id="p3"></a>

3. Сүт зауыттары мен сүт цехтары

<a id="p4"></a>

4. Ет комбинаттары мен шұжық цехтары

<a id="p5"></a>

5. Жеміс және ет консервілері цехтары

<a id="p6"></a>

6. Балық өндеуші кәсіпорындар

<a id="p7"></a>

7. Сыраалкоголсіз кәсіпорындар

<a id="p8"></a>

8. Спиртарақ және сыра құюшы кәсіпорындар

<a id="p9"></a>

9. Диірмендер мен жарма дайындаушы кәсіпорындар

<a id="p10"></a>

10. Макарон цехтары

<a id="p11"></a>

11. Өсімдік майлары мен майонездер өндіру жөніндегі цехтар

<a id="p12"></a>

12. Құрылыс индустриясының өнеркәсіп кәсіпорындары (құрылыс материалдарының радиациялық қауіптілік сыныбын анықтау)

<a id="p13"></a>

13. Азықтық өнімдер және балалар ойыншықтарымен байланыста бола отырып, тауарлар шығарушы кәсіпорындар

<a id="p14"></a>

14. Су құбырлары және канализациялық-тазарту қондырғылары

<a id="p15"></a>

15. Жұмыс орындарын аттестациялау бойынша өнеркәсіп, көлік, байланыс, құрылыс, энергетика және басқа салалардың кәсіпорындары
