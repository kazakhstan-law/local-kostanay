# О создании областного центра делового сотрудничества

> *Сноска. Утратило силу решением акима Костанайской области от 09.12.2004 № 53.*

В целях развития и поддержки малого и среднего бизнеса РЕШИЛ:

1. Создать областной центр делового сотрудничества в организационно-правовой форме государственного предприятия на право хозяйственного ведения.

2. Уполномоченным органом, осуществляющим функции управления и субъекта права государственной собственности по отношению к областному центру делового сотрудничества, определить департамент по поддержке малого среднего бизнеса Костанайской области (Мочалкин О.Д). Для формирования уставного фонда областного центра делового сотрудничества передать департаменту по поддержке малого среднего бизнеса из фонда коммунальной собственности акима области основные средства на сумму 6600 тыс.тенге.

3. Департаменту по поддержке малого и среднего бизнеса Костанайской области (Мочалкин О.Д.) совместно с управляющим делами аппарата акима (Мусабеков Е. А.) решить вопрос по выделению рабочих площадей для размещения областного центра делового сотрудничества в здании по ул. Тарана, 87.

4. Поручить департаменту по поддержке малого и среднего бизнеса Костанайской области подготовить для областного центра делового сотрудничества учредительные документы.

5. Контроль за выполнением настоящего решения возложить на заместителя акима области Ашимова Н.С.
