# Денисов ауданының аумағында сайлау учаскелерін құру туралы

Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі «Қазақстан Республикасындағы сайлау туралы» Конституциялық заңының 23-бабына сәйкес ШЕШІМ ҚАБЫЛДАДЫ:

1. Қосымшаға сәйкес Денисов ауданының аумағында сайлау учаскелері құрылсын.

2. Денисов ауданы әкімінің 2014 жылғы 27 қаңтардағы № 2 «Денисов ауданының аумағында сайлау учаскелерін құру туралы» (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде № 4476 болып тіркелген, 2014 жылғы 27 наурызда «Наше время» газетінде жарияланған) шешімінің күші жойылды деп танылсын.

3. Осы шешімнің орындалуын бақылау Денисов ауданы әкімі аппаратының басшысына жүктелсін.

4. Осы шешім алғашқы ресми жарияланған күнінен кейін қолданысқа енгізіледі.
