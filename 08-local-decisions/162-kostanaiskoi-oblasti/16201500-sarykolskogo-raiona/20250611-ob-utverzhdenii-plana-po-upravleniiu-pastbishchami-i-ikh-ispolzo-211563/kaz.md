# Сарыкөл ауданы бойынша 2025-2029 жылдарға арналған жайылымдарды басқару және оларды пайдалану жөніндегі жоспарды бекіту туралы

«Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабы 1-тармағының 13) тармақшасына, «Жайылымдар туралы» Қазақстан Республикасы Заңының 8-бабына сәйкес Сарыкөл аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. Қоса беріліп отырған Сарыкөл ауданы бойынша 2025-2029 жылдарға арналған жайылымдарды басқару және оларды пайдалану жөніндегі жоспар бекітілсін.

2. Осы шешім оның алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Сарыкөл аудандық мәслихатының төрағасы**

**Д. Әбжамалов**

> *Мәслихаттың*  
> *2025 жылғы 11 маусымдағы*  
> *№ 309 шешімімен бекітілген*

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| [`ch001`](kaz/ch001.md) | 1-тарау. Жалпы ережелер |
| [`part003`](kaz/part003.md) | Өңірдің жер балансының және мемлекеттік жер кадастрының ақпараттық жүйесінің деректері |
| [`part003-t001-r001`](kaz/part003-t001-r001.md) | таблица 1, строки 1–929 |
| [`part003-t001-r002`](kaz/part003-t001-r002.md) | таблица 1, строки 930–1104 |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
